# Chaotic Random: website

The public site for the Chaotic Random game, hosted on GitHub Pages:

- `index.html`: the home page
- `privacy.html`: the privacy policy (English and Portuguese), linked from AdMob, Google Play, the App Store
  and the app's Settings. Keep it in step with what the app collects (see the game's `docs/BACKEND.md`).
- `app-ads.txt`: tells ad buyers which AdMob account may sell ads in the app. It must be at the root of the
  developer website listed in both stores.
