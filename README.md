# Chaotic Random: website

The public site of Chaotic Random, the studio (and its first game), hosted on GitHub Pages at chaoticrandom.com:

- `index.html`: the studio home, listing the games
- `chaotic-random/`: the Chaotic Random game's page (add one folder per new game)
- `boti/`: Bot.i, the coding game for kids: its page, its own privacy policy (`boti/privacy.html`, English and
  Portuguese; Bot.i collects no personal data, so it doesn't share the Chaotic Random policy), icon and link preview image
- `privacy.html`: the Chaotic Random game's privacy policy (English and Portuguese), linked from AdMob, Google Play, the App Store
  and the app's Settings. Keep it in step with what the app collects (see the game's `docs/BACKEND.md`).
- `app-ads.txt`: tells ad buyers which AdMob account may sell ads in the app. It must be at the root of the
  developer website listed in both stores, and covers every game in the same AdMob account.
